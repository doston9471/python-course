# Python Basics — Before OOP

Runnable lessons covering Python syntax from zero until you're ready for OOP.

## How to run

```bash
python3 01_basics/01_hello_and_print.py
```

## Curriculum

1. Hello & print — running a file, comments, print
2. Variables & types — ints, floats, strings, bools, None
3. Strings — f-strings, indexing, slicing, common methods
4. Numbers & operators — arithmetic, comparison, truthiness
5. Lists (arrays) — create, index, slice, mutate, list methods
6. Dicts (hashes) — keys/values, get, nest, iterate
7. Tuples & sets — immutability, uniqueness
8. Conditionals — if / elif / else, match / case (switch), and / or / not
9. Loops — for, while, range, break / continue, enumerate
10. Functions — def, return, defaults, *args / **kwargs
11. Comprehensions — list/dict/set comps (Pythonic shortcuts)
12. Files & errors — open/read/write, try / except / finally
13. Modules & imports — import, from, aliases, `__main__`
14. Useful builtins — zip, lambda, map/filter, sorting, `is` vs `==`
15. JSON & pathlib — structured data and modern file paths

When you're done here, continue with `02_oop_and_solid/01_classes_and_objects.py`.
